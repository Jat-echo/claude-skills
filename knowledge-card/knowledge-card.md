# 知识卡片生成 Skill

将任意长文、书摘、笔记或知识点，提炼核心结构，以**架构图、关系图、流程图**等可视化方式生成知识卡片，用图形帮助理解，文字仅作简短标注。

## 调用方式

```
/knowledge-card [内容或主题]
```

- 直接粘贴长文内容，或简述主题
- 不传参数时，Claude 会提示你输入内容

---

## 执行流程

### Step 1：分析知识结构，选择可视化类型

首先判断内容的内在逻辑，选择最能帮助理解的图形类型：

| 知识结构 | 适合的可视化类型 |
|---------|--------------|
| 概念之间有层级/从属关系 | 树形结构图 / 思维导图 |
| 多个要素相互影响、循环 | 关系网络图 / 循环图 |
| 有先后顺序、步骤流程 | 流程图 / 时间轴 |
| 两个维度对比分析 | 四象限矩阵 / 对比表格 |
| 整体由多个部分构成 | 结构拆解图 / 模块图 |
| 因果推导链 | 因果链图 / 金字塔图 |

---

### Step 2：设计可视化结构

用简洁的符号/ASCII 或描述语言规划图的布局：

- **节点**：每个概念用最短的词语表达（≤6字）
- **连线**：用关系动词标注（→ 导致、← 来自、⇄ 互相影响、⊂ 属于）
- **层级**：不超过 3 层，保持视觉清爽
- **重点标注**：1-2 个核心节点加粗或高亮，其余作为支撑

整张卡片的文字总量控制在 **50 字以内**（不含标题和来源）。

---

### Step 3：生成知识卡片图像

基于 Step 2 的结构设计，立即使用当前客户端的原生图像生成能力，用以下提示词生成图像：

```
一张以「{可视化类型}」为主体的知识卡片，主题：{核心主题}

可视化内容：
{Step 2 设计的结构，用文字描述节点、连线和层级关系}

视觉风格：
- 画幅：16:9 横向，留白充足
- 配色：莫兰迪色系（低饱和度灰蓝/灰绿/米白/藕粉），核心节点用深色强调
- 图形：几何线条简洁清晰，手绘质感，节点用圆角矩形或圆形
- 文字：极简标注，字号适中，中文优先，钢笔书写质感
- 背景：米白或浅灰，干净无噪
- 底部：小字注明来源「{来源}」
- 禁止：大段文字、项目符号列表、复杂装饰
```

各客户端调用方式：

| 客户端 | 生图方式 |
|--------|---------|
| **Claude Code / claude.ai** | Claude 直接调用内置图像生成工具输出图像 |
| **Codex** | Codex 原生调用 GPT Image 2（`gpt-image-1`）生成 |
| **ChatGPT 网页** | ChatGPT 内置图像生成直接输出 |
| **Gemini** | Gemini 调用 Imagen 生成 |

> 无需任何 API Key 或额外配置，直接把提示词交给当前客户端生成即可。

---

### Step 4：微调

- **图形类型**：若效果不理想，在提示词中明确指定，如"改用四象限矩阵"、"改用时间轴"
- **色调**：替换为"暖棕莫兰迪"、"深色背景"、"蓝绿系"
- **密度**：若节点过多，要求"精简为最核心的 5 个节点"

## 示例

**输入：**
```
/knowledge-card 《深度工作》：在无干扰状态下专注于认知要求极高的工作，
能创造新价值、提升技能，且难以复制。浮浅工作容易复制，价值低。
```

**Step 1 分析：**
- 结构类型：两种工作模式的对比 + 深度工作的价值链
- 选择：**对比 + 因果链图**（左右对比两种状态，右侧展开深度工作的价值推导）

**Step 2 结构设计：**
```
[浅层工作]              [深度工作]
 · 易复制         VS     · 无干扰专注
 · 低价值                    ↓
                         创造新价值
                            ↓
                         技能持续提升
                            ↓
                         难以被复制
```

**Step 3 提示词：**
```
一张以「对比+因果链图」为主体的知识卡片，主题：深度工作 vs 浅层工作

可视化内容：
左侧：「浅层工作」节点，向下连接「易复制」「低价值」两个子节点
右侧：「深度工作」节点，向下依次连接「无干扰专注」→「创造新价值」→「技能持续提升」→「难以被复制」
左右之间用 VS 符号分隔，右侧链条用箭头表示因果递进

视觉风格：
- 画幅：16:9 横向，留白充足
- 配色：莫兰迪色系，「深度工作」侧用深色强调
- 图形：圆角矩形节点，手绘线条质感
- 文字：极简标注，中文，钢笔书写质感
- 背景：米白，干净无噪
- 底部：小字注明来源「《深度工作》Cal Newport」
- 禁止：大段文字、项目符号列表
```

## 注册为 /knowledge-card 斜杠命令

```bash
# macOS / Linux
curl -o ~/.claude/commands/knowledge-card.md \
  "https://raw.githubusercontent.com/Jat-echo/claude-skills/refs/heads/main/knowledge-card/knowledge-card.md"
```

```powershell
# Windows
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Jat-echo/claude-skills/refs/heads/main/knowledge-card/knowledge-card.md" `
  -OutFile "$env:USERPROFILE\.claude\commands\knowledge-card.md"
```
